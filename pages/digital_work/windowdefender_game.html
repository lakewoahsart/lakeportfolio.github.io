-=WINDOWDEFENDER=-



This project is about interpreting the project prompt of "intervention" into blocking and parrying in a game. My process for the creation of this game was simple, figuring out the general mechanics first and foremost, and then going into establishing the aesthetics and dynamics. I decided to use the previous system that I had built for the simple ball game excersise, and expand on it in order to create more of an active challenging experience for the player. This project is important to me because it was the first interactive game that I've built from the ground up on my own. I have worked on projects like this before in a collaborative environment, but handling all the aspects of the project was a unique learning experience. My approach to this project was loosely inspired by "my website is a shifting house" by Laurel Schwulst in the sense that it was built with systems that are modular in nature and can easily be built off of in the future such as the speed array for the enemies and the player color pallete system, and also lightly aesthetically inspired by Nick Briz's "Thoughts on Glitch[Art]v2.0" in the usage of computer aspects like text windows as the play area.

CONTROLS:
BLOCK IN DIRECTION - ARROW KEYS
PAUSE - P
RESUME - R
PRESS 0, 1, 2, or 3 for alternate color palletes.

Click the image to play the game!

[note: do not press pause on non-level pages like the main menu, it will break the experience and require a refresh to fix]
